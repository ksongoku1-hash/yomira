# Yomira 0.1.9 — flecha pequeña para ordenar capítulos

El control de orden ahora es una flecha pequeña junto al listado, tanto al buscar capítulos para descargar como al abrir los guardados para leer:

- **↑**: capítulos de menor a mayor.
- **↓**: capítulos de mayor a menor.

Pulsa la flecha para cambiar el orden. Su explicación aparece al dejar el cursor encima. Se conserva el manejo por teclado, las selecciones, los filtros y la pausa por manga.

Descarga **Yomira-Setup-0.1.9.exe** y ejecútalo. Para actualizar, cierra Yomira antes de instalar; los mangas y el progreso se guardan fuera de la carpeta del programa. No necesitas pip, Python ni Node.js.

También hay una versión portátil: extrae todo **Yomira-Windows-x64-0.1.9.zip** y abre Yomira.exe. Se incluyen FMD adaptado y sus licencias; su código fuente correspondiente y las sumas SHA-256 se ofrecen en esta Release.

Versión de prueba para Windows 10/11 x64, sin firma digital. No se ha certificado en un segundo ordenador.
