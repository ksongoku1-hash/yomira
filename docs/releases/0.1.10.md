# Yomira 0.1.10 — actualizaciones sin parpadeo

Las consultas automáticas de estado ya no desactivan ni atenúan los botones, ni cambian sus textos cada pocos segundos. La biblioteca, la ficha del manga, Buscar, Descargas y el historial de exportaciones USB conservan sus controles mientras reciben datos nuevos.

Las descargas y los capítulos siguen actualizándose automáticamente. Los avisos de carga se reservan para la carga inicial, el cambio de página y las acciones que solicitas. Al pulsar Actualizar, se mantiene la indicación de progreso y se evitan solicitudes repetidas. El recuento de capítulos incorporados permanece visible sin aparecer y desaparecer con cada revisión de carpetas.

Se conserva la flecha pequeña **↑ / ↓** para ordenar capítulos, los filtros, la selección y la pausa por manga.

Descarga **Yomira-Setup-0.1.10.exe** y ejecútalo. Para actualizar, cierra Yomira antes de instalar; los mangas y el progreso se guardan fuera de la carpeta del programa. No necesitas pip, Python ni Node.js.

También hay una versión portátil: extrae todo **Yomira-Windows-x64-0.1.10.zip** y abre Yomira.exe. Se incluyen FMD adaptado y sus licencias; su código fuente correspondiente y las sumas SHA-256 se ofrecen en esta Release.

Versión de prueba para Windows 10/11 x64, sin firma digital. No se ha certificado en un segundo ordenador.
