# Yomira 0.1.12 — lector híbrido local

Entrega local para Windows x64. La versión incorpora los avances H2c y H3a: lectura online progresiva con imágenes en RAM, descarga explícita del capítulo actual, selección o manga completo dentro del lector y progreso asociado al mismo capítulo al abrir su CBZ.

Se conservan los modos del lector, la biblioteca, búsqueda, exportaciones y el motor de descargas con validación, publicación atómica y ComicInfo.xml. La interfaz y las dependencias existentes permanecen. El catálogo de selección muestra 100 filas por página y la creación de trabajos usa lotes de hasta 100.

El paquete usa el motor nativo H2c ya verificado; su SHA-256 coincide con `third_party/fmd2/upstream.json`. Se conservan licencias y se entrega el código correspondiente del motor adaptado. La compilación usa CPython 3.14.7, PyInstaller 6.22.3, Node 24.21.0 e Inno Setup 7.1.0.

Antes de activar una actualización, guardar y verificar una copia del perfil completo y una copia consistente de SQLite, comprobar el esquema y comparar capítulos, progreso y preferencias en una migración de prueba. La base actual migra de `0023_whole_manga_export_size` a `0024_reader_sessions`. No intentar abrir esa base con una versión anterior sin recuperar también una base compatible.

La activación local utiliza un directorio nuevo y el perfil elegido por el usuario, sin mezclarlo con AlphaData. El instalador se compila, pero su instalación/desinstalación no se certifica en este Windows personal: todavía requiere una VM o Sandbox desechable. No se modifican las reglas de conservación o eliminación del instalador.

No se publica una Release remota. Quedan navegación entre capítulos online, recuperación de un proveedor reiniciado, aceptación de fuentes externas y verificación en otro ordenador. Leer online requiere conexión y RAM; aplicación, configuración y progreso siguen ocupando disco. Las descargas requieren sus archivos y los márgenes de seguridad existentes.
