# Yomira 0.1.7 — 10 de octubre de 2026

## Instalar y abrir

Descarga `Yomira-Setup-0.1.7.exe`, abre el archivo, pulsa Instalar y Finalizar.
El instalador está en español, instala para el usuario actual sin permisos de
administrador, crea accesos directos y ofrece abrir Yomira al terminar.
El ejecutable abre la página cuando el servidor está listo. Una segunda apertura
vuelve a abrir la interfaz si Yomira ya está disponible en el mismo puerto.

Se incluyen Python, la interfaz compilada, FMD2 adaptado y licencias. El ZIP
portátil se abre con `Yomira.exe` después de extraer todo su contenido. El motor
FMD y su código fuente correspondiente son los mismos que en la Release anterior.

## Cambios incluidos

- Interfaz reciente con fondos ilustrados, navegación y modo de gráficos sencillos.
- Mejoras del lector, presentación y controles de lectura.
- Corrección de identidad de obras para reutilizar fichas compatibles y evitar duplicados.
- Reutilización de capítulos disponibles de otras fuentes cuando la identidad es inequívoca.
- Corrección del número visible de capítulos FMD y del ancho de la lista de capítulos.

Las correcciones particulares de registros de una biblioteca local no se
distribuyen como datos: cada usuario conserva su biblioteca y progreso.

## Verificación de esta entrega

- Compilación de interfaz y comprobación de tipos aprobadas; lint de interfaz aprobado.
- 283 pruebas de interfaz aprobadas en 17 archivos.
- 134 pruebas seleccionadas de backend aprobadas: arranque del navegador, identidad,
  importación, API de descargas, FMD y recursos de empaquetado.
- Ruff y tipos aprobados en el código nuevo de arranque y sus pruebas.
- PyInstaller construyó el ejecutable e Inno Setup construyó el instalador.
- Controles de instalador aprobados: instalación por usuario, accesos directos,
  protección de instancia y ausencia de borrado de biblioteca/datos.
- Recursos web empaquetados idénticos a la compilación; motor FMD con SHA-256
  coincidente con la versión de referencia.

La prueba de arranque del ejecutable con raíces temporales fue bloqueada por
otra instancia de Yomira que estaba abierta. No se detuvo esa instancia ni se
modificó su biblioteca. No se certifica una instalación en un segundo ordenador.
El instalador no tiene firma digital. Esta es una versión de prueba para Windows x64.
