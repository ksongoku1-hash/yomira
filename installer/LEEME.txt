YOMIRA 0.1.16 — LECTOR HIBRIDO PARA WINDOWS 10/11 X64

Version 0.1.16 distribuida desde GitHub Releases.

INSTALAR: abre Yomira-Setup-0.1.16.exe. Cierra la version anterior antes
de actualizar. Conserva una copia de recuperacion de tus datos y progreso.
El programa y la biblioteca se guardan en carpetas separadas.

VERSION PORTATIL: extrae TODO Yomira-Windows-x64-0.1.16.zip y abre
Yomira.exe. No lo ejecutes dentro del ZIP. Se incluyen el motor y licencias;
no necesitas instalar Python, Node.js ni FMD por separado.

LECTURA ONLINE: en Buscar abre Leer online. Las paginas se solicitan
progresivamente y se reutilizan desde memoria y una cache temporal local en disco,
sin crear una descarga en la biblioteca. Necesitas conexion para paginas nuevas.
La aplicacion conserva configuracion y progreso en disco.

DESCARGAS: abre Descargar dentro del lector para guardar el capitulo actual,
varios capitulos seleccionados o el catalogo completo disponible del manga.
Las descargas usan la cola existente, verifican los archivos y crean CBZ
con ComicInfo.xml. Abrir el CBZ conserva el progreso del capitulo.

DATOS: el perfil predeterminado es %LOCALAPPDATA%\Yomira\YomiraData.
Los mangas nuevos van a Documentos\Mangas de Yomira, incluida una ubicacion
redirigida a OneDrive. La instalacion conserva el perfil y la biblioteca existentes; no incluye datos
personales ni el perfil de desarrollo de E:.

La interfaz se abre en el navegador al iniciar. Cerrar la pestana no detiene
el programa. Para cerrar la consola de una ejecucion manual, pulsa Ctrl+C.
No abras dos versiones simultaneamente.

Se conservan exportaciones, modos de lectura y organizacion de descargas.
Se incluyen licencias en Licencias y Motor\licenses y el codigo del motor
adaptado en la entrega. Version de prueba sin firma digital; comprueba las
sumas SHA-256 de los archivos recibidos.

CONTINUIDAD: puedes pasar al capitulo anterior o siguiente de la misma fuente
e idioma. Si una pagina falla, Reintentar pagina reabre el capitulo y conserva
la posicion. Si cambia su cantidad de paginas, el lector detiene la reapertura
para proteger el progreso guardado.

La recuperacion tras un cierre inesperado del motor se verifica en Windows
con una fuente ficticia. Quedan pendientes fuentes externas y una prueba del
instalador en un Windows limpio. Las fuentes pueden cambiar o dejar de responder;
utiliza unicamente accesos autorizados y respeta sus limites.

ACTUALIZACIONES: la version instalada busca versiones estables en GitHub y descarga
el instalador en segundo plano. Pulsa Reiniciar y actualizar cuando este listo.
La version portatil se actualiza manualmente desde Releases.
Si vienes de 0.1.11 u otra version sin actualizador, instala esta entrega
manualmente una vez. Las siguientes actualizaciones apareceran dentro de Yomira.

FUENTES: 21 integraciones, con disponibilidad que depende de cada sitio.
Inventario Oculto y Ragnarok actualizan sus catalogos en segundo plano.
Cartel De Manhwas no tiene actualmente un catalogo utilizable.

RECOMENDACIONES: el ranking publico de MangaDex ayuda a descubrir titulos.
Buscar fuentes comprueba donde esta disponible cada obra; el historial de lectura
no se envia al proveedor del ranking.
